# Local network access

Run the following command from this folder to serve the site to other devices on the same network:

```bash
python serve_site.py
```

Then open the displayed local IP address in a browser from another device, for example:

```text
http://192.168.x.:8080/
```

If you want to keep it running in the background, use a terminal session and leave t open.

Default credentials for accessing the website are as follows:

for the administrative end

```text
username: admin
password: admin123
```

for the user end

```text
username: student-example
password: passwd
```
